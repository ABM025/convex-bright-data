## About convex-bright-data

convex-bright-data helps you save data from Bright Data SERP results and Web Unlocker. It stores the results safely using a system called Convex. You can set how long the saved data stays available with simple settings called TTLs (time to live). The program also lets you adjust queries easily. This makes it simple to keep and check the data you need.

convex-bright-data works on Windows. It is designed for users who want to manage data without needing to understand complex tools or code.

## 📥 Using convex-bright-data

The user interface is simple. Here’s how to use it for your main tasks.

### Add a new data cache

1. Click on “Add Cache” or “New Query”
2. Enter your search details or data source settings
3. Set how long you want to keep the data (TTL). For example, 7 days or 30 minutes
4. Click “Save” or “Start”

### Check saved data

- Go to the “Cache List” section
- Click any item to view details
- You can refresh the data if needed using the “Update” button

### Remove old data

convex-bright-data deletes data automatically after the TTL expires. You can also delete caches manually:

- Select the item
- Click “Delete”

### Adjust settings

Find the “Settings” or “Preferences” menu to:

- Change default TTL values
- Set update frequencies for queries
- Manage storage limits
